# Arquitetura proposta

```text
Web App -> API/autenticação
  -> Intake Agent (texto, PDF e imagem)
  -> Flight / Hotel / Attractions / Transport Agents
  -> Budget & Optimization Agent
  -> Report Agent
  -> banco de dados + monitoramento
```

Cada preço futuro deve registrar fonte, moeda, horário da consulta, regras e URL. O relatório deve distinguir fatos extraídos, dados consultados e inferências.
